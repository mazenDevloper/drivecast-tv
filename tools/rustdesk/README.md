# RustDesk — شوف شاشة التلفزيون وتحكّم فيه من أي مكان

## ١. خادمك الخاص (اختياري لكنه أسرع)
الخوادم العامة المجانية تشتغل، لكنها أحياناً بطيئة. خادمك الخاص يخلّي الاستجابة شبه فورية.

**أين تشغّله مجاناً:**
- **Oracle Cloud — Always Free** (الأفضل): جهاز ARM مجاني دائماً، اختر أقرب منطقة (مثلاً Dubai أو Jeddah).
- **Google Cloud e2-micro**: مجاني في مناطق أمريكا فقط (أبعد → تأخير أكثر).
- **جهاز في البيت شغّال دائماً** (لابتوب قديم / Raspberry Pi) مع فتح المنافذ في الراوتر.

**التشغيل** (على الجهاز السحابي، Ubuntu):
```bash
curl -fsSL https://raw.githubusercontent.com/mazenDevloper/drivecast-tv/main/tools/rustdesk/setup-server.sh | sudo bash
```
يطبع في الأخير: **ID server** و **Relay server** و **Key**.

**افتح المنافذ في جدار السحابة** (Oracle: Security List · Google: VPC firewall):
TCP `21115-21119` و UDP `21116`.

## ٢. التلفزيون (مرة وحدة، وأنت على شبكة البيت)
```bash
bash tools/rustdesk/tv-setup.sh 192.168.100.147
```
السكربت:
- يختار نسخة التطبيق المناسبة لأندرويد الجهاز نفسه — **كثير من أجهزة TV Box تشغّل أندرويد 32-بت على معالج 64-بت**، فنسخة arm64-v8a ما تنثبّت عليها؛ السكربت يقرأ نوع النظام ويختار armv7 أو aarch64.
- يسمح بتصوير الشاشة مرة وحدة (ما تطلع رسالة «ابدأ الآن؟» على التلفزيون كل مرة).
- يشغّل خدمة التحكم (Accessibility) **بجانب** ماوس DriveCast بدون ما يلغيه.
- يستثنيه من توفير الطاقة (ما يقفله النظام في الخلفية).

بعدها على التلفزيون مرة وحدة: RustDesk ← الإعدادات ← الشبكة: ضع ID / Relay / Key، ثم **كلمة مرور دائمة**، ثم «تشغيل الخدمة» و«التشغيل مع الإقلاع».

## ٣. التابلت / الجوال / الكمبيوتر
ثبّت RustDesk، ضع نفس ID / Relay / Key، اكتب رقم التلفزيون (ID) وكلمة المرور.
- **اللمس**: وضع «الماوس» = إصبعك يحرّك المؤشر · وضع «اللمس» = نقرتك تضغط مكانها مباشرة على شاشة التلفزيون.
- **لوحة المفاتيح**: زر الكيبورد في شريط RustDesk.

## ٤. مشاركة الملفات
- من الكمبيوتر: زر «نقل الملفات» في نافذة الاتصال — اسحب الملف للتلفزيون أو منه.
- من الجوال للتلفزيون: نفس الشي من قائمة الاتصال ← «نقل الملفات».

## نصائح
- كلمة مرور دائمة قوية، وفعّل «الاتصال بكلمة المرور فقط».
- لا تشارك رقم الجهاز وكلمة المرور مع أحد.
- إذا انقطع بعد إعادة تشغيل التلفزيون: افتح RustDesk مرة على التلفزيون وتأكد أن «التشغيل مع الإقلاع» مفعّل.
